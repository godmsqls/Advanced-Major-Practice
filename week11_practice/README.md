2. 위에서 아래로 모든 셀을 순서대로 실행합니다. CPU로도 실행할 수 있습니다.
3. week11_results 폴더에서 생성된 그래프와 digits_cnn.keras 모델을 확인합니다.

## 포함 파일
- week11_cnn.ipynb: 단계별 안내와 전체 실행 코드
- week11_cnn.py: 동일한 실행 코드. 로컬 실행 시 tensorflow, numpy, matplotlib, scikit-learn이 필요합니다.
- digits_split.npz: 실제 분할에 사용한 이미지/정답/인덱스. 노트북은 load_digits()를 사용하므로 별도 업로드할 필요가 없습니다.
- reference_results/: 실제 실행 결과, 그래프, 학습된 예제 모델
- 실험기록.csv: 검증 결과 기록 양식
- DATA_SOURCE.txt: 데이터 출처와 원자료 이용 조건

## 데이터와 평가
데이터는 scikit-learn 내장 digits(1,797장, 8×8, 값 0~16)입니다. MNIST가 아닙니다.
학습 1,077장, 검증 360장, 테스트 360장으로 분할하며 seed=42를 사용합니다.
이번 표본 단위 분할은 작성자 독립 분할을 보장하지 않습니다. 실제 영상 프로젝트는 사람/동영상/촬영 세션 단위로 분리하세요.
모델 선택은 검증 데이터로 진행하고 최종 테스트를 반복해 최적화하지 마세요.

## 실제 실행 예
TensorFlow 2.20.0, CPU, seed=42. 환경에 따라 결과가 달라질 수 있습니다.
Dense 검증 정확도 94.44%, CNN 검증 정확도 97.50%, CNN 테스트 정확도 96.67%(348/360).
기준 CNN 파라미터 수는 9,258개입니다. 모델 저장 후 재불러온 예측과 원래 예측의 일치를 확인했습니다.
수업 자료의 숫자는 예시 실행 결과이며 목표 정확도를 보장하지 않습니다.
